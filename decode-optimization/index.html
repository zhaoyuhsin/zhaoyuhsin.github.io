02 / REPEATABILITY

均值接近，不代表每轮都稳定。

仅 2 次独立启动

EP8 · 拼接实现

11 个 BS 中，9 个的两次均值差异小于 1%。BS1024 为 5.84%，BS2048 为 2.95%。

BS1024：2554.56 → 2409.54 μs。对应 MegaMoE 耗时收益分别为 58.17% / 55.58%，大幅领先不依赖某一次偏慢。

EP32 · 拼接实现

11 个 BS 中，9 个的两次均值差异小于 1%。BS1024 为 1.30%，BS2048 为 2.78%。

以上是逐轮 rank-min 的后10轮均值差异，不描述单轮尾部；20轮采样不等于20次独立实验。

两次差异 = |启动 A − 启动 B| ÷ 双轮均值 ×100%。这是重复性观测，不是置信区间，也不保证长期稳定。上方筛选会同时列出两种实现、两种 rank 口径的启动差异。

03 / PROTOCOL & EVIDENCE

先把分母和版本说清楚。

固定模型
H7168 · I3072 · 384 experts · TopK6 · shared0；路由权重 FP4 E2M1 / E8M0 scale，激活 FP8。
输入与节点
每 rank BS；均衡 rank-first 路由；seed 20260922。EP8 与 EP32 均为同柜，候选与参考使用各自窗口内相同节点。
采样协议
每配置正序 / 反序两次独立启动；每次 warmup10，采样20取后10；先逐轮跨 rank 归约，再求轮次与启动均值。
端到端含义
NPU Event 包围完整调用，含实际通信、计算与设备空隙；不是各小算子最小耗时相加，也不是 CPU 请求端到端。
参考执行方式
BS≤512：decode Dispatch/CombineV2 路径；BS≥1024：prefill Alltoall 路径。eager 串行，无图模式或共享专家多流优化。
测量边界
双方 Profiler Level1 / PipeUtilization 开启，设备内部 timer 关闭；当前无共享对照没有内部 timer trace。Profiler 可影响主机发射空隙，不能外推无 Profiler 引擎收益。
容量与跨 EP 边界
进程内 HCCL buffer 6000MB。EP8 MegaMoE 按 BS 建 buffer；EP32 会话复用 capacity4096。计时外生命周期不同，跨 EP 差异不能全归因到 EP。
性能与精度分开
accuracy=not_run_user_requested；仅性能，不宣称精度通过或生产合入就绪。新页不重跑实验，不上传原始 trace 或机器信息。
